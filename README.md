# Ghi chú nhanh — QuickNote Android
Ứng dụng Android 8+; widget 2×2 gồm 3 ghi chú. Chạm ô vuông để đánh dấu, chạm nội dung để sửa, nút + thêm ghi chú. Dữ liệu lưu cục bộ, không cần Internet.
APK thử nghiệm được tạo bằng GitHub Actions; tải ở Releases hoặc Artifacts. Sau khi cài, mở ứng dụng và chọn thêm widget.
